# Security

This plugin gives an AI agent instructions for working on a real home. Please report anything that could make an agent:

- change a device, the configuration or the instance without the user's approval,
- act on locks, alarm panels, covers, valves or sirens without a separate approval per action,
- print, log or commit a token or a value from `secrets.yaml`,
- or follow instructions hidden in a configuration, a log or a web page.

Report privately through GitHub's **Report a vulnerability** (Security tab of this repository). Please do not open a public issue for these. Other bugs and wrong Home Assistant facts are welcome as normal issues.
